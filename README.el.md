# AI Social

[English](README.md) | **Ελληνικά**

Μια μικρή εφαρμογή που τρέχει **στον υπολογιστή σου**. Συνδέεις **X (Twitter)**, **LinkedIn** και
**Facebook Page**, το AI γράφει τα posts (και, αν θέλεις, φτιάχνει εικόνα) και τα δημοσιεύεις αμέσως ή τα
προγραμματίζεις για αργότερα.

- Το AI γράφει **μία εκδοχή για κάθε πλατφόρμα** (σύντομη για το X, πιο αναλυτική για το LinkedIn κ.λπ.),
  στο ύφος της επιχείρησής σου. Τη διορθώνεις ελεύθερα πριν βγει.
- Θέματα: γράφεις δικό σου, διαλέγεις από τη λίστα σου ή παίρνεις ένα τυχαίο. Το AI προτείνει και νέα θέματα.
- Εικόνες: ανεβάζεις δική σου ή τη φτιάχνει το AI (χρειάζεται OpenAI key).
- Αρχική σελίδα με την εβδομάδα σου, πόσα δημοσίευσες και ό,τι θέλει προσοχή.
- Προγραμματισμός με ημερομηνία και ώρα, ιστορικό posts, retry με ένα κλικ.
- Interface στα Αγγλικά, με ελληνικά ως επιλογή στο Settings → Language.
- Τα keys και τα tokens αποθηκεύονται **κρυπτογραφημένα** μόνο στον υπολογιστή σου.

---

## Γρήγορο ξεκίνημα

1. Εγκατέστησε **Python 3.10 ή νεότερη** (δωρεάν, δες παρακάτω).
2. Ξεκίνα την εφαρμογή:
   - **macOS:** διπλό κλικ στο `start.command`
   - **Windows:** διπλό κλικ στο `start.bat`
   - **Linux:** `./start.sh`
3. Ανοίγει μόνος του ο browser στο **http://localhost:5050** με τον **οδηγό πρώτης ρύθμισης**.

Την πρώτη φορά η εκκίνηση θέλει 1-3 λεπτά και internet: φτιάχνεται ένα ιδιωτικό περιβάλλον Python
(`.venv`), κατεβαίνουν οι βιβλιοθήκες και δημιουργείται το αρχείο `.env` με ένα τυχαίο κλειδί
κρυπτογράφησης. Από εκεί και πέρα ξεκινά σε λίγα δευτερόλεπτα.

**Άφησε ανοιχτό το παράθυρο που ανοίγει** (terminal). Όσο είναι ανοιχτό, η εφαρμογή τρέχει. Για να τη
σταματήσεις: `Ctrl+C` ή κλείσιμο του παραθύρου. Τα μηνύματα σε αυτό το παράθυρο είναι στα Αγγλικά.

## 1. Εγκατάσταση Python (μία φορά)

| Σύστημα | Τι κάνεις |
|---|---|
| **macOS** | Κατέβασε τον installer από https://www.python.org/downloads/ και τρέξ' τον. Αν έχεις Homebrew: `brew install python`. |
| **Windows** | Κατέβασε από https://www.python.org/downloads/. Στην πρώτη οθόνη του installer **τσέκαρε «Add python.exe to PATH»**. |
| **Linux (Ubuntu/Debian)** | `sudo apt install python3 python3-venv` |

Η Python που έχει ήδη το macOS (3.9) είναι παλιά. Το `start.command` την προσπερνά και ψάχνει νεότερη.

## 2. Πρώτη εκκίνηση

- **macOS:** διπλό κλικ στο `start.command`. Αν το macOS πει ότι δεν μπορεί να ανοίξει αρχείο από άγνωστο
  developer: **δεξί κλικ → Άνοιγμα → Άνοιγμα** (μία φορά), ή System Settings → Privacy & Security →
  «Open Anyway». Αν βγει «permission denied», άνοιξε Terminal στον φάκελο και τρέξε
  `chmod +x start.command start.sh`.
- **Windows:** διπλό κλικ στο `start.bat`. Αν εμφανιστεί «Windows protected your PC»: **More info → Run anyway**.
- **Linux:** `./start.sh` (ή `python3 start.py`). Για server χωρίς browser: `python3 start.py --no-browser`.

Αν ο browser δεν ανοίξει μόνος του, άνοιξε χειροκίνητα το **http://localhost:5050**.

## 3. Οδηγός πρώτης ρύθμισης (στον browser)

Η εφαρμογή είναι στα **Αγγλικά**, και ο οδηγός πρώτης ρύθμισης επίσης, γι' αυτό τα κουμπιά του γράφονται εδώ
στα Αγγλικά. Για ελληνικό interface, μετά τον οδηγό πήγαινε στο **Settings → Language** και διάλεξε
**Ελληνικά**. Οι υπόλοιπες ενότητες γράφουν τα κουμπιά όπως φαίνονται στα Ελληνικά.

Ο οδηγός έχει 4 βήματα. Ό,τι παραλείψεις το κάνεις αργότερα από το **Settings** (**Ρυθμίσεις**).

1. **AI:** επικόλλησε ένα API key. Προτείνεται το **Claude (Anthropic)** για τα κείμενα. Το **OpenAI**
   χρειάζεται μόνο για εικόνες με AI (ή αν το προτιμάς και για κείμενο). Με το **Save** γίνεται και
   αυτόματος έλεγχος ότι το key δουλεύει.
2. **Business:** όνομα, τι κάνεις, ύφος γραφής, γλώσσα των posts και η λίστα με τα θέματα για posts.
3. **Accounts:** πρόσθεσε X, LinkedIn ή Facebook Page. Κάθε πλατφόρμα έχει μέσα στην εφαρμογή οδηγό
   βήμα-βήμα (**Step-by-step guide**), τον ίδιο με αυτόν πιο κάτω.
4. **Finish:** λίστα με ό,τι είναι έτοιμο και ό,τι λείπει. Το **Finish setup** σε πάει στην αρχική σελίδα.

## AI keys

### Claude (Anthropic), προτείνεται για το κείμενο
1. https://platform.claude.com → λογαριασμός / login.
2. Settings → **Billing**: πρόσθεσε λίγα credits (π.χ. 5$). Κάθε post κοστίζει συνήθως λίγα cents.
3. Settings → **API keys** → «Create key».
4. Αντέγραψε το key (ξεκινά με `sk-ant-`) και επικόλλησέ το στο AI Social. Φαίνεται μόνο μία φορά.

Προεπιλεγμένο μοντέλο: `claude-opus-5-5` με χαμηλό effort (γρήγορο και φθηνότερο). Αλλάζει από το `.env`.
Αν το Claude αρνηθεί ένα θέμα για λόγους ασφαλείας, το Anthropic API δοκιμάζει αυτόματα το προτεινόμενο
εναλλακτικό μοντέλο (server-side fallback).

### OpenAI, για εικόνες με AI (και εναλλακτικά για κείμενο)
1. https://platform.openai.com → login.
2. Settings → **Billing**: πρόσθεσε credits.
3. Για εικόνες: Settings → Organization → General → **Verify Organization** (το ζητά το OpenAI για τα
   μοντέλα εικόνας).
4. https://platform.openai.com/api-keys → «Create new secret key» → επικόλλησέ το στο AI Social.

Κάθε εικόνα χρεώνεται στον λογαριασμό σου στο OpenAI. Μπορείς πάντα να ανεβάζεις δικές σου εικόνες δωρεάν.

## Σύνδεση λογαριασμών

Στο **Ρυθμίσεις → Λογαριασμοί** (ή στο βήμα 3 του οδηγού) διάλεξε την πλατφόρμα δίπλα στο **Πρόσθεσε:**.
Η φόρμα δείχνει τον ίδιο οδηγό με παρακάτω, στο **Οδηγός βήμα-βήμα**.

Με αγγλικό interface (και μέσα στον οδηγό πρώτης ρύθμισης) τα κουμπιά λέγονται: **Πρόσθεσε:** = **Add:**,
**Αποθήκευση** = **Save**, **Αντιγραφή** = **Copy**, **Σύνδεση LinkedIn** = **Connect LinkedIn**,
**Επανασύνδεση** = **Reconnect**, **Οδηγός βήμα-βήμα** = **Step-by-step guide**.

### X (Twitter), περίπου 10 λεπτά
1. https://developer.x.com → login με τον λογαριασμό που θα κάνει τα posts. Αν ζητηθεί, φτιάξε developer
   account και γράψε σύντομα τη χρήση (π.χ. «Δημοσίευση posts της επιχείρησής μου»).
2. Developer Portal → άνοιξε το App σου (ή φτιάξε νέο App μέσα σε ένα Project).
3. App → **User authentication settings → Set up**: App permissions = **Read and write**, Type of App =
   «Web App, Automated App or Bot», Callback URI = `http://localhost:5050`, Website URL = η σελίδα σου
   (ή `https://example.com`). Save.
4. App → **Keys and tokens → API Key and Secret → Regenerate**. Αντέγραψε API Key και API Key Secret.
5. Στο ίδιο σημείο → **Access Token and Secret → Generate**. Πρέπει να γράφει **«Read and Write»**. Αν γράφει
   μόνο «Read», πάτα Regenerate (φτιάχτηκε πριν το βήμα 3).
6. Επικόλλησε τα 4 keys στο AI Social → **Αποθήκευση** (γίνεται και αυτόματος έλεγχος).

Το X χρεώνει τη χρήση του API. Αν ένα post αποτύχει με σφάλμα 402 ή 403 για credits, πρόσθεσε credits ή
διάλεξε πλάνο στο developer portal.

### LinkedIn (προσωπικό προφίλ), περίπου 10 λεπτά
1. https://www.linkedin.com/developers/apps → **Create app**.
2. App name, LinkedIn Page, logo, αποδοχή όρων. Το LinkedIn ζητά μια **Company Page**: αν δεν έχεις, φτιάξε
   μια απλή από το «Create a LinkedIn Page».
3. Καρτέλα **Products**: πρόσθεσε **Share on LinkedIn** και **Sign In with LinkedIn using OpenID Connect**
   (εγκρίνονται αμέσως).
4. Καρτέλα **Auth → Authorized redirect URLs → Add redirect URL** και βάλε **ακριβώς**:
   `http://localhost:5050/oauth/linkedin/callback`
   (το AI Social το δείχνει με κουμπί **Αντιγραφή**).
5. Στην ίδια καρτέλα αντέγραψε **Client ID** και **Primary Client Secret** → επικόλλησέ τα στο AI Social →
   **Αποθήκευση**.
6. Πάτα **Σύνδεση LinkedIn**, κάνε login, έγκρινε. Επιστρέφεις αυτόματα στο AI Social.

Η σύνδεση ισχύει **60 μέρες**: μετά πατάς **Επανασύνδεση** (η εφαρμογή το δείχνει μια εβδομάδα πριν λήξει και
δεν σε αφήνει να προγραμματίσεις post για μετά τη λήξη). Τα posts γίνονται στο **προσωπικό σου προφίλ**. Για
Company Page το LinkedIn ζητά ειδική έγκριση (Community Management API), που δεν υποστηρίζεται.

### Facebook Page, περίπου 15 λεπτά
Χρειάζεσαι μια **Σελίδα** (όχι προσωπικό προφίλ) που διαχειρίζεσαι.
1. https://developers.facebook.com/apps → **Create App**. Διάλεξε χρήση για διαχείριση Σελίδας
   (π.χ. «Manage everything on your Page») ή «Other» → «Business».
2. Άνοιξε τον **Graph API Explorer**: https://developers.facebook.com/tools/explorer/ και διάλεξε το app
   σου πάνω δεξιά.
3. Στα **Permissions** πρόσθεσε: `pages_show_list`, `pages_read_engagement`, `pages_manage_posts`.
   Πάτα **Generate Access Token** και έγκρινε για τη Σελίδα σου.
4. Για token που δεν λήγει: https://developers.facebook.com/tools/debug/accesstoken/ → επικόλλησε το token
   → **Debug** → **Extend Access Token** → αντέγραψε το νέο token.
5. Πίσω στον Graph API Explorer: βάλε το νέο token στο πεδίο «Access Token» και τρέξε το query
   `me/accounts`. Στη Σελίδα σου αντέγραψε το `id` (= **Page ID**) και το `access_token`
   (= **Page Access Token**).
6. Επικόλλησέ τα στο AI Social → **Αποθήκευση**.

Όσο το app είναι σε Development mode, δημοσιεύει κανονικά σε Σελίδες που διαχειρίζεσαι εσύ.

### Instagram
Δεν υποστηρίζεται ακόμα: το API του Instagram θέλει την εικόνα ανεβασμένη σε δημόσιο URL, ενώ το AI Social
τρέχει τοπικά στον υπολογιστή σου.

## Καθημερινή χρήση

**Αρχική:** η ημερομηνία, πότε βγαίνει το επόμενο post και **Η εβδομάδα σου**: οι επόμενες 7 μέρες με κάθε
προγραμματισμένο post. Το **Προσθήκη** σε μια μέρα ανοίγει νέο post έτοιμο για εκείνη τη μέρα. Μέχρι να είναι
έτοιμα τα βασικά, το **Ξεκίνα εδώ** δείχνει τι λείπει (AI key, λογαριασμός, πρώτο post). Μετά το πρώτο post
εμφανίζονται και τα βασικά νούμερα, γράφημα με τα posts ανά εβδομάδα (και προβολή **Πίνακας**), η κατανομή ανά
πλατφόρμα, τα πρόσφατα αποτελέσματα και η κατάσταση των λογαριασμών.

**Νέο post:**
1. **Πού θα δημοσιευτεί;** Τσέκαρε τους λογαριασμούς.
2. **Τι θα γράψει το AI;** Γράψε θέμα (ή διάλεξε από τη λίστα σου ή πάτα **Τυχαίο**), διάλεξε μήκος και πρόσθεσε
   προαιρετικές οδηγίες (π.χ. «ανέφερε την προσφορά -20% μέχρι την Κυριακή»). Πάτα **Γράψε με AI**: βγαίνει
   ένα κείμενο για κάθε πλατφόρμα, με μετρητή χαρακτήρων.
3. **Κείμενο:** διόρθωσέ το ελεύθερα ή πάτα **Ξαναγράψε**.
4. **Εικόνα** (προαιρετικό): **Ανέβασε εικόνα** ή **Εικόνα με AI**.
5. **Δημοσίευση:** **Τώρα**, ή **Αργότερα** με ημερομηνία και ώρα (ή **Σε 1 ώρα**, **Αύριο 09:00**, **Αύριο 18:00**).

Η **Προεπισκόπηση** δείχνει περίπου πώς θα φαίνεται κάθε post. Το πρόχειρο κρατιέται αν κλείσεις κατά λάθος τη σελίδα.

**Posts:** ό,τι έχεις προγραμματίσει ή δημοσιεύσει, ανά ημέρα, με φίλτρα (Προγραμματισμένα, Δημοσιευμένα,
Αποτυχημένα, Ακυρωμένα). Σε ένα προγραμματισμένο post αλλάζεις κείμενο και ώρα (**Επεξεργασία**), το στέλνεις
αμέσως (**Δημοσίευση τώρα**) ή το ακυρώνεις (**Ακύρωση**). Ένα αποτυχημένο το ξαναστέλνεις με
**Ξαναδοκίμασε**, αφού διορθώσεις την αιτία που γράφει το μήνυμα.

### Προγραμματισμός: πρέπει να τρέχει η εφαρμογή
Τα προγραμματισμένα posts δημοσιεύονται **μόνο όσο τρέχει το AI Social** (ανοιχτό παράθυρο, υπολογιστής
αναμμένος και όχι σε sleep). Αν ήταν κλειστό την ώρα που έπρεπε:
- μέχρι **6 ώρες** καθυστέρηση: το post βγαίνει μόλις ξανανοίξεις την εφαρμογή,
- πάνω από 6 ώρες: σημειώνεται **Απέτυχε** (για να μη βγει άκαιρα) και το ξαναστέλνεις από τα Posts.

Στο macOS, για να μην κοιμηθεί ο υπολογιστής όσο τρέχει: `caffeinate -i ./start.sh`.

### Γλώσσα
Το **Ρυθμίσεις → Γλώσσα** αλλάζει μενού, κουμπιά και μηνύματα ανάμεσα σε Αγγλικά και Ελληνικά, για όλη την
εφαρμογή. Τα αρχικά θέματα και το ύφος γραφής ακολουθούν την αλλαγή όσο δεν τα έχεις πειράξει· ό,τι έγραψες
εσύ δεν αλλάζει ποτέ. Η γλώσσα **των posts** είναι ξεχωριστή ρύθμιση: **Γλώσσα των posts**, στο **Επιχείρηση και
θέματα**. Αν μείνει κενή, το AI γράφει στη γλώσσα του θέματος.

## Αντιμετώπιση προβλημάτων

| Πρόβλημα | Λύση |
|---|---|
| Το παράθυρο γράφει «Python 3.10 or newer was not found» | Εγκατέστησε Python από https://www.python.org/downloads/ και ξαναδοκίμασε. Στα Windows τσέκαρε «Add python.exe to PATH». |
| Η εγκατάσταση βιβλιοθηκών απέτυχε | Χρειάζεται internet την πρώτη φορά. Ξαναδοκίμασε. |
| «Port 5050 is in use by another program» | Γράψε `AISOCIAL_PORT=5051` στο `.env`. Αν χρησιμοποιείς LinkedIn, άλλαξε και το redirect URL στο LinkedIn app σε `http://localhost:5051/oauth/linkedin/callback` (και το Callback URI στο X app). |
| Δεν άνοιξε ο browser | Άνοιξε http://localhost:5050. Αν τρέχει ήδη, το start script απλώς ανοίγει τη σελίδα. |
| X: 401 | Λάθος keys. Αντέγραψέ τα ξανά (χωρίς κενά). |
| X: 403 | Το app δεν έχει «Read and write» (μετά την αλλαγή ξαναφτιάξε το Access Token), ή δεν υπάρχουν credits, ή το ίδιο κείμενο έχει ήδη δημοσιευτεί. |
| X: 402 | Ο developer λογαριασμός δεν έχει credits ή πλάνο για posting. |
| LinkedIn: «redirect_uri does not match» | Το redirect URL στο LinkedIn app πρέπει να είναι **ακριβώς** `http://localhost:5050/oauth/linkedin/callback`. |
| LinkedIn: 403 | Λείπει το product «Share on LinkedIn». Πρόσθεσέ το και μετά πάτα **Επανασύνδεση**. |
| LinkedIn: «Η σύνδεση LinkedIn έληξε» | Πάτα **Επανασύνδεση** (κάθε 60 μέρες). |
| Facebook: «Το Page Access Token δεν ισχύει ή έληξε» (190) | Βγάλε νέο Page Access Token (βήματα 3-5 παραπάνω). |
| «Τα αποθηκευμένα στοιχεία δεν διαβάζονται» | Άλλαξε το `APP_SECRET` στο `.env`. Επανάφερε το παλιό `.env` (υπάρχει `.env.bak` αν έτρεξες `init --new-key`) ή βάλε ξανά τα keys στις Ρυθμίσεις. |
| Post που απέτυχε με «…ίσως δημοσιεύτηκε» | Η σύνδεση κόπηκε την ώρα της αποστολής. Έλεγξε την πλατφόρμα πριν το ξαναστείλεις, για να μη βγει δύο φορές. |
| Σφάλμα AI (key, credits, όριο) | Έλεγξε key και credits στο Anthropic ή στο OpenAI. Το **Έλεγχος σύνδεσης AI** στο Ρυθμίσεις → AI δείχνει τι φταίει. |

Τα μηνύματα μέσα στην εφαρμογή βγαίνουν στη γλώσσα που έχεις διαλέξει (τα αγγλικά κείμενα είναι στο
[README.md](README.md)). Το παράθυρο (terminal) της εφαρμογής γράφει πάντα στα Αγγλικά, και εκεί φαίνονται οι
λεπτομέρειες για κάθε σφάλμα.

## Ασφάλεια και δεδομένα

- Η εφαρμογή ακούει μόνο τοπικά (localhost: ο υπολογιστής σου). Άλλες συσκευές του δικτύου δεν συνδέονται.
- API keys και tokens αποθηκεύονται **κρυπτογραφημένα** (Fernet) στο `instance/aisocial.db`, με κλειδί το
  `APP_SECRET` του `.env`. Η εφαρμογή δεν τα ξαναδείχνει ποτέ (μόνο τους 4 τελευταίους χαρακτήρες).
- Προστασία από άλλες ιστοσελίδες στον ίδιο browser (CSRF, DNS rebinding) και αυστηρό Content-Security-Policy.
- **Μην μοιράζεσαι το `.env` και τον φάκελο `instance/`.** Δεν μπαίνουν ποτέ στο git.
- Πρόσβαση από άλλη συσκευή (προχωρημένο): `AISOCIAL_HOST=0.0.0.0`, **υποχρεωτικά** `AISOCIAL_PASSWORD=...`
  και `AISOCIAL_PUBLIC_URL=` τη διεύθυνση που θα ανοίγεις. Ιδανικά πίσω από HTTPS reverse proxy.

### Backup / μεταφορά σε άλλον υπολογιστή
Αντέγραψε το αρχείο **`.env`** και τον φάκελο **`instance/`**. Χωρίς το ίδιο `.env`, τα αποθηκευμένα keys
δεν διαβάζονται (θα πρέπει να μπουν ξανά). Το `.venv` δεν χρειάζεται: ξαναφτιάχνεται μόνο του.

## Ρυθμίσεις για προχωρημένους (`.env`)

Όλα είναι προαιρετικά, εκτός από το `APP_SECRET` που φτιάχνεται αυτόματα. Μετά από αλλαγή, ξεκίνα ξανά την εφαρμογή.

| Μεταβλητή | Προεπιλογή | Τι κάνει |
|---|---|---|
| `AISOCIAL_PORT` | `5050` | Θύρα. |
| `AISOCIAL_HOST` | `127.0.0.1` | Διεύθυνση που ακούει. Άλλη τιμή απαιτεί `AISOCIAL_PASSWORD`. |
| `AISOCIAL_PUBLIC_URL` | `http://localhost:<port>` | Η διεύθυνση της εφαρμογής (για το LinkedIn redirect). |
| `AISOCIAL_PASSWORD` | – | Κωδικός πρόσβασης (Basic auth). |
| `AISOCIAL_ALLOWED_HOSTS` | – | Επιπλέον host names που δέχεται, χωρισμένα με κόμμα (π.χ. πίσω από reverse proxy). |
| `ANTHROPIC_API_KEY`, `OPENAI_API_KEY` | – | Keys από εδώ αντί από τον browser (υπερισχύουν). |
| `AI_TEXT_PROVIDER` | `auto` | `auto`, `anthropic` ή `openai`. |
| `ANTHROPIC_MODEL` | `claude-opus-5-5` | Μοντέλο Claude. |
| `ANTHROPIC_EFFORT` | `low` | `low`, `medium`, `high`, `xhigh` ή `max`. |
| `OPENAI_TEXT_MODEL` | `gpt-5-mini` | Μοντέλο OpenAI για κείμενο. |
| `OPENAI_IMAGE_MODEL` | `gpt-image-1` | Μοντέλο OpenAI για εικόνες. |
| `LINKEDIN_API_VERSION` | αυτόματα | LinkedIn API version (YYYYMM). Συνήθως δεν χρειάζεται. |
| `FACEBOOK_GRAPH_VERSION` | `v26.0` | Graph API version. |
| `AISOCIAL_DB_PATH` | `instance/aisocial.db` | Βάση δεδομένων. |
| `AISOCIAL_MEDIA_DIR` | `instance/media` | Εικόνες που ανέβηκαν ή φτιάχτηκαν. |
| `AISOCIAL_SCHEDULER_INTERVAL` | `15` | Κάθε πόσα δευτερόλεπτα ελέγχονται τα προγραμματισμένα. |
| `AISOCIAL_MAX_LATE_MINUTES` | `360` | Πόση καθυστέρηση επιτρέπεται πριν ένα post σημειωθεί «Απέτυχε». |

Εντολές (από τον φάκελο της εφαρμογής, με την Python του `.venv`):
- `python -m aisocial run --open`: εκκίνηση
- `python -m aisocial init`: δημιουργία `.env` αν λείπει
- `python -m aisocial init --new-key`: νέο `APP_SECRET` (κρατά backup στο `.env.bak`, τα keys μπαίνουν ξανά)

Τα tests δεν κάνουν κλήσεις στο internet: οι πλατφόρμες και τα AI SDKs αντικαθίστανται με fakes.
Η δομή του κώδικα περιγράφεται στο [README.md](README.md#for-developers). Κάθε κείμενο που βλέπει ο χρήστης
γράφεται και στις δύο γλώσσες εκεί που χρησιμοποιείται: `L("Save", "Αποθήκευση")` σε Python, Jinja και JavaScript.

## Γνωστοί περιορισμοί
- Instagram: δεν υποστηρίζεται.
- LinkedIn: μόνο προσωπικό προφίλ· νέα σύνδεση κάθε 60 μέρες.
- X: το API έχει κόστος από το X.
- Τα προγραμματισμένα posts χρειάζονται την εφαρμογή ανοιχτή.
- Οι κλήσεις στις πλατφόρμες έχουν γραφτεί πάνω στην τεκμηρίωσή τους και ελέγχονται με tests, όμως οι
  πλατφόρμες αλλάζουν συχνά κανόνες: κάνε ένα **δοκιμαστικό post** σε κάθε λογαριασμό στην αρχή.
